# Hi, I'm Umut.

I build tools to make everyday tasks a little easier. Most of my projects start with something I want to simplify, whether that's converting files or getting a GitHub project running on my computer.

I like keeping things straightforward: useful features, a clear interface, and as little setup as possible.

## What I'm working on

- **[FileForge](https://github.com/UmutAlisoglu/fileforge)** — tools for documents, PDFs, images, and video. Use the [browser tools](https://alisoglu.com/tools/) or the [Windows app](https://github.com/UmutAlisoglu/fileforge/releases/latest), with file processing on your own device.
- **[Repodock](https://github.com/UmutAlisoglu/repodock)** — a Windows dashboard for downloading and running GitHub projects, with their logs and controls in one place. [Download](https://github.com/UmutAlisoglu/repodock/releases/latest).
- **PCB AIO Tool** — currently building this one. More to share as it comes together.

You can find more of my work at **[alisoglu.com](https://alisoglu.com/)**.
